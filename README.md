# Hospitality Telegram Bot 🏨🤖

Универсальный Telegram бот для мониторинга, управления бронированиями и уведомлений гостеприимных объектов (гостевые дома, базы отдыха, хостелы и т.д.)

## ✨ Функциональность

### Для клиентов 👥
- 📱 **Просмотр информации об объекте** - полное описание, удобства и условия
- 💰 **Ознакомление с ценами** - подробный прайс-лист всех услуг
- 📅 **Онлайн бронирование** - интерактивная форма заказа номера
- ✅ **Проверка доступности** - статус занятости номеров
- 🔔 **Управление уведомлениями** - получение информации о статусах бронирований
- 📞 **Контактная информация** - быстрый доступ к телефону, сайту, соцсетям
- ⭐ **Отзывы** - информация о том, где оставить отзыв

### Для администраторов ⚙️
- 📋 **Управление бронированиями** - просмотр, редактирование статусов
- 📊 **Статистика** - аналитика забронированных услуг
- 🔔 **Система уведомлений** - оповещения о новых заказах
- 📡 **Мониторинг доступности** - отслеживание занятости
- 📰 **Мониторинг отзывов** - получение уведомлений о новых отзывах
- 📢 **Рассылка сообщений** - отправка информации пользователям

## 🚀 Быстрый старт

### Требования
- Python 3.9+
- pip

### Установка

1. **Клонируйте репозиторий**
```bash
git clone https://github.com/ggggady-lgtm/hospitality-telegram-bot.git
cd hospitality-telegram-bot
```

2. **Создайте виртуальное окружение**
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

3. **Установите зависимости**
```bash
pip install -r requirements.txt
```

4. **Настройте переменные окружения**
```bash
cp .env.example .env
```
Отредактируйте `.env` файл со своими данными:
```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
ADMIN_USER_ID=123456789
ADMIN_CHAT_ID=123456789

# Информация об объекте
PROPERTY_NAME=Гостевой дом "Байкальская звезда"
PROPERTY_ADDRESS=пос. Утулик, Кедровый переулок, 5
PROPERTY_PHONE=+7 (908) 648-53-32
PROPERTY_WEBSITE=http://baikalstar38.ru
PROPERTY_TELEGRAM=https://t.me/baikalskay_zvezda
```

5. **Запустите бота**
```bash
python main.py
```

## 🛠️ Команды бота

### Основные команды
```
/start - Начало работы, главное меню
/help - Справка по всем командам
/info - Информация об объекте
/prices - Прайс-лист услуг
/book - Начать процесс бронирования
/contacts - Контактная информация
/notifications - Управление уведомлениями
```

### Админ-команды
```
/admin - Админ-панель
/bookings - Список всех бронирований
/stats - Статистика использования услуг
```

## 🗄️ База данных

Бот использует SQLite с таблицами:
- **users** - Информация о пользователях
- **bookings** - Список бронирований
- **availability** - Доступность услуг по датам
- **reviews** - Отзывы из разных источников
- **notifications** - История отправленных уведомлений
- **admin_logs** - Логи действий администраторов

## 📝 Пример конфигурации услуг

Все услуги и цены настраиваются в `config.py`:

```python
SERVICES = {
    'main_house_14': {
        'name': 'Основной дом (14 человек)',
        'price': 40000,
        'currency': '₽',
        'unit': 'сутки'
    },
    # ... остальные услуги
}
```

## 🔐 Безопасность

- Токен бота хранится в переменных окружения (`.env`)
- База данных расположена локально
- Админ-функции доступны только пользователю с `ADMIN_USER_ID`
- Все команды логируются

## 🔄 Автоматический мониторинг

Бот включает автоматические задачи (APScheduler):
- Проверка доступности услуг каждые N часов
- Мониторинг новых отзывов
- Автоматические уведомления пользователям
